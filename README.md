# Study Weather

Study Weather is a unique study planner that helps you adapt your work to your current mental climate instead of forcing a rigid schedule.

## Concept

Your brain has a weather pattern:
- Sunny: high energy, low friction
- Cloudy: moderate focus, need structure
- Rainy: low energy, easier tasks only
- Stormy: overloaded, take recovery actions

Rather than a fixed to-do list, Study Weather helps you choose the right kind of work based on how your mind feels today.

## Features

- Energy and focus check-in
- Dynamic task matching by current mental state
- Task difficulty and energy scoring
- Gentle, encouraging guidance instead of guilt-based productivity
- Privacy-first: no tracking, no account required

## Run locally

Open `index.html` in a browser or serve the folder with any static server.

Example:

```bash
python3 -m http.server 8000
```

Then visit: `http://localhost:8000`

## MVP idea

This project is intentionally simple: a single-page prototype for the concept with a polished UI and an interactive forecast.
